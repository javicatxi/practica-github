# practica-github
Práctica de creación y gestión de un repositorio de código


## Propósito
Aprender a crear y gestionar un repositorio de código utilizando GitHub.

## Descripción
Este repositorio forma parte de una actividad de Programación y Robótica.
En él se practica la creación de un repositorio, la subida de archivos y
el control de diferentes versiones mediante commits.
